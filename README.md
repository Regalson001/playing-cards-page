# 🃏 Page of Playing Cards

A responsive, Flexbox-powered web application that renders stylized playing cards using semantic **HTML5** and advanced **CSS3 Flexbox** properties.

---

## 📌 Overview

The **Page of Playing Cards** lab demonstrates how to leverage CSS Flexbox for both container alignment and precise child element layout. By combining `align-self`, `justify-content`, and column directions, each playing card visually aligns corner suits and center motifs with precision.

---

## ✨ Key Features

- **Flexbox Grid Container**: Uses `#playing-cards` to dynamically wrap items and maintain centered spacing across screen sizes.
- **Corner & Center Alignment**: Employs `align-self: flex-start`, `align-self: center`, and `align-self: flex-end` for suit symbols (`.left`, `.middle`, `.right`).
- **Rotated Bottom Corner**: Rotates `.right` elements `180deg` for traditional playing card corner aesthetics.
- **Flexible Card Layout**: Clean vertical stack inside `.middle` using `flex-direction: column`.

---

## 🛠️ Built With

* **HTML5**: Semantic markup (`main`, `div`, `span`).
* **CSS3**: Flexbox properties (`gap`, `flex-wrap`, `align-self`, `justify-content`), CSS transitions, and transform attributes.
